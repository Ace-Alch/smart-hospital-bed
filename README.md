## Scope

Combine patient-related sensing, bed positioning and networked visualization in a prototype. The documentation separates the stated project scope, inspected artifacts and future work. A listed feature is not a new test result.

### Main elements

- Heart-rate and EMG sensors
- Environmental and motion sensors
- Embedded acquisition
- Servo positioning
- Node-RED display
